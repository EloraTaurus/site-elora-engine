## How the surfaces connect

The main website explains the project. Engineering records mechanisms, maturity,
source-review context and validation limits. The public dashboard presents
runtime summaries. Public Reports contains deliberately exported public-safe
artefacts. Each report retains its own scope, examined build and recorded result.

The public Agent overview describes connection scope; it does not grant access
to all Research records. Broader analysis, drafting, rendering and publication
remain separate governed integrations. Memory Delivery is experimental and
does not establish general effectiveness or production learning changes.
