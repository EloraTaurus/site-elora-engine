Portable Determinism

Elora Engine Protocol

A compatibility-first research programme for expressing selected Engine behaviour through versioned, language-neutral contracts and deterministic conformance evidence.

All CapabilitiesArchitecture

Protocol Boundaries

The protocol isolates stable behavioural boundaries without exposing private implementation details or coupling every implementation to one language.

Signal and Semantic Engines

Versioned inputs and outputs support deterministic behaviour-signal and semantic interpretation boundaries.

Governance Decisions

Governance evaluation can be expressed as a bounded contract while authority remains with the surrounding identity, policy, and commit systems.

Threat Detection

Threat findings can use stable result envelopes and evidence semantics without publishing the private detector implementation.

Pipeline Composition

Explicit boundaries make engine participation, ordering, compatibility, and failure states inspectable.

Conformance and Portability

Versioned Manifests

Declared versions and capabilities allow callers to reason about compatibility rather than relying on implicit implementation behaviour.

Canonical Evidence

Canonical serialization, stable hashes, golden corpora, and conformance tests support comparison between compatible implementations.

Migration Discipline

Existing behaviour is characterized and frozen before a boundary is moved, reducing the risk of silent semantic drift.

Measured Execution

Resource-governance and benchmark evidence can compare implementations without making portability synonymous with unrestricted execution.

Research Direction

The protocol is not a plugin marketplace and does not transfer governance authority. It is a path toward portable, testable Engine components whose behaviour can be independently checked.
