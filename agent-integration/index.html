What is available, and what is still experimental

The public integration demonstration is scoped to synthetic, read-only evidence. Local tests cover the connection and permission boundaries; this guide does not establish acceptance by every MCP client or access to the wider Research collection.

Bounded synthetic implementations include staged task plans, retained task-ledger evidence and review holds. They remain synthetic development work. Bespoke analysis, report drafting, rendering and publication require their own governed integration and approval boundaries before availability can be claimed.

Agent controls and investigation

Pause, permissions and containment

Routine Pause/Resume is separate from security suspension, revocation and synthetic containment. Current authority and bounded resource admission are checked for the supported operation; recovery does not silently restore revoked grants.

Task plans and retained history

Synthetic task plans and a hash-linked Task Ledger retain checkpoints and review holds. Selected-Agent investigation supports stable audit IDs, bounded search and exact incident/control reference groups, with safe contextual inspection.

Decisions and stage evidence

Agent Decisions and Threat Intelligence views project existing receipts and ordered, payload-free reached gateway stages. Missing terminal or transport observations stay unknown; these views do not establish shared threat-store integration or visibility into external reasoning.

Reviewed 29 October 2026. These are bounded implementation scopes, not general client acceptance or complete Research execution. Engine 0.2.11 is selected for deployment; 0.3.0 remains subject to agreed end-to-end Agent acceptance.
