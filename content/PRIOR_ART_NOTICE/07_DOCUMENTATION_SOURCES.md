## Usage Notes

- These sources support capability-to-implementation mapping.
- Public disclosure entries remain intentionally high-level and avoid sensitive operational details.
- If source docs and disclosure entries diverge, update disclosure with dated notes rather than deleting prior chronology.
- Treat public reports as operator-published project evidence, not independent validation.
- Do not infer a missing run date from a filename, filesystem timestamp or later export/publication date.
