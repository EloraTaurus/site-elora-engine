Workspace and Governed Document Review

The September 2026 Workspace preview brings document tasks into a conversation while retaining Engine-owned admission, evidence and release decisions.

Attach, Describe, Send

Select or upload an authorised text or Markdown document, attach it and describe the review. Attachment alone does not start inference. Originals remain private, and only permitted derived context may reach the configured model.

Governed Review

Recorded checks cover access, inspection, context preparation, useful response allowance, model eligibility, completion, approval and release. A failed mandatory check holds the review; a completed provider request does not itself authorise a response.

Understand the Outcome

The interface shows recorded progress, model context, provider-wait boundaries and evidence-based explanations. The Workspace Skill Journey preserves the distinction between prevented dispatch, incomplete output, post-inference holds and release.

Profiles and Permission Tests

A collapsible Elora panel and responsive account menu include in-place profile details and internally stored photos. Admins can test separate synthetic tool, AI and agent policies; those grants do not change authenticated identity or enable unavailable applications.

Initial Scope

Document Review initially supports text and Markdown with the configured Ollama adapter. Sensitivity inspection is a bounded baseline, not a complete sensitive-data or malware scanner. Broader formats and providers remain future work.

Availability and Evidence

These are implemented preview capabilities with local checks recorded in the changelog. Deployment and live-provider verification remain separate. Demo organisation and subscription labels are placeholders; external identity synchronisation is not connected.
