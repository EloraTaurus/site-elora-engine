Sense and Execution Atlas

Sense brings Elora's observational runtime tools into one workbench. Execution Atlas explores retained execution structure, measurements, relationships, and evidence gaps without changing scheduling, policy, or commit authority.

A Runtime Workbench

Sense organises investigation by capability and ownership rather than presenting one undifferentiated status dashboard.

Models

Inspect recorded model availability, size and compatibility evidence, compare supported capabilities, and explore model structure where the relevant adapter exposes it. Capability evidence does not itself authorise routing.

Engine Runtime

Inference Governor, Memory Governance, Performance and Storage Governor tools share a consistent investigation surface while retaining separate ownership and control boundaries.

Module Ownership

Sense can show the Engine module or managed service associated with available resource evidence. Ownership labels remain separate from whole-machine attribution.

On-Demand Diagnostics

Resource-heavy inspections are bounded and demand-scoped. Removing broad background sampling reduces observer overhead without claiming that all transient or browser costs are measured.

Execution Atlas

Atlas is an observational map of retained work, not an execution controller.

Recorded Structure

Explore available stages, pipeline nodes, provider attempts, adapter operations and terminal evidence in recorded order. Order alone does not establish dependency or causation.

Scoped Measurements

Thread CPU, process CPU, operation wall time and provider elapsed time are labelled separately. Nested totals are not treated as additive, and missing measurements remain unknown.

Evidence Relationships

Relationships require retained identity evidence. Shared processes, timing proximity or matching labels do not silently become causal or authority links.

Longer Histories

Bounded paging supports investigation across longer Observer histories without loading the entire retained evidence set into one view.

What Sense Does Not Claim

  • Recorded sequence is not proof of causation.
  • Provider elapsed time is not remote model CPU.
  • Module ownership is not whole-host utilisation.
  • Missing evidence is not zero activity.
  • Observation does not grant scheduling, intervention, policy, or commit authority.
